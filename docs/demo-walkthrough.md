# 問い合わせ支援AI：デモ手順

## 準備

本番データとは別のローカルAPI・DBを使います。API起動後、リポジトリ直下で `py -3.13 apps/api/tools/seed_demo.py` を実行すると、同名の進行可能なサンプルを再利用し、なければ作成します。出力された案件パスをWebで開きます。デモ用アカウントは開発環境のシードを利用します。

## 説明順（約10分）

|順番|画面と操作|伝えること|
|---|---|---|
|1|案件概要の「次に対応すること」|現在不足している判断・担当・証拠をここから確認する|
|2|工程の右矢印からタスクを開く|必要な工程と担当を確認し、詳細で期限・成果物を記録する|
|3|概要に戻り、台帳検索で「評価計画」|初期の18行は雛形。入力あり0/18から始まり、入力と承認は区別する|
|4|台帳の行を開いて保存する|必要項目を編集し、検証結果と正本確認の状態を確認する|
|5|スキル画面で必要スキル・評価履歴を開く|担当配置と評価の有効期限を確認する。評価操作には責任ロールが必要|
|6|案件設定→案件の保管→アーカイブ|保管後は閲覧専用。案件を再開するには理由を記録し、リスク前提を再確認する|
|7|企業のレポート画面で生成・ダウンロード|保存した実データの集計をPDF・CSVで取得する|

工程の矢印には操作名があり、キーボードでも移動できます。編集途中で閉じた場合は破棄確認が出ます。取得に失敗した場合は未確認と表示され、「再試行」で復旧できます。

## デモでの説明上の制約

AIレビューとコード実行は未接続のため、利用可能として紹介しません。空のテンプレート、入力あり、正本確認済みを同じ意味で説明しません。旧版ですでにアーカイブされていた案件には保管当時のスナップショットがなく、過去時点の再現は保証できません。新たにアーカイブした案件から保管時点の判定を保持します。
