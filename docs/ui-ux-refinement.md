# UI・UX改善 実装記録

更新日：2026-09-11。ローカルコードへ反映済み。本番へのデプロイは未実施。

## 方針と変更

現在の状況と次の操作を先に示し、詳細な基準・参照資料・履歴は必要なときに開く。管理用ID・台帳キー・権限判定を維持し、表示文言を整理した。

| 対象 | 変更内容 |
|---|---|
| 共通文言 | 長い見出しと説明を短縮。「案件管理」「学習プラン」「プロジェクト提案」などの呼称をナビとページで統一。未提供・未確認・期限切れの意味は保持 |
| 共通表示 | 業務画面のヘッダーを小さくし、グラデーション・影を抑制。余白、入力欄、ボタン、見出し、フォーカス表示を統一 |
| ダイアログ | 小型モーダルと右ドロワーを共通化。背景操作の抑止、Tab循環、Escape、閉じた後のフォーカス復帰、未保存確認、保存中の閉じる操作抑止を実装 |
| タブ | 左右キー・Home・Endで選択とフォーカスを移動 |
| 案件一覧 | 一覧を中心にし、新規作成はドロワーへ。機能・条件の入力は折りたたみ |
| 案件概要 | 要対応リンク、次の判断、進捗を先に表示。前提条件とメンバー管理はドロワーへ移動。アーカイブ・メンバー解除は影響を示して確認 |
| 台帳への導線 | 用途別の折りたたみと名前検索を追加。該当する台帳は検索時に直接表示 |
| 工程タスク | 実施内容・成果物・完了条件を先に表示。担当ロールと参照資料は折りたたみ。保存を固定フッターへ。未保存で閉じる際は明示的に選択 |
| 台帳編集 | 記入ルールと定義を折りたたみ。確認者等のサーバー記録は確認・履歴情報へ分離。保存・独立確認を固定フッターへ。競合時の下書き保持・比較・取り込みを維持 |
| 台帳の状態変更 | 状態保存のレスポンスから新しいrevisionを保持。編集中の他項目は保持し、その後の保存で古い版を再送しない |
| 承認 | 有効な判断、未充足理由、完了タスク数を先に表示。判断記録と必要証拠は詳細へ |
| スキル | 現在の評価・編集・履歴を分離。既存の履歴APIへ接続し、訂正・取消履歴を表示。保存を固定フッターへ。取消理由と影響を確認して取消 |
| チーム | 一覧を中心にし、作成・招待・一括招待は小型モーダルへ。招待権限に応じた操作表示、日本語の役割名、参加リンクのコピーを追加 |
| 業務課題 | 登録をドロワーへ。初期値は空欄とし、入力例は操作した場合のみ使用。既存APIで保存されない補助入力欄は除去 |
| レポート | 課題と受講者の選択→内容確認・ダウンロード→履歴の順に整理。選択内容の詳細は折りたたみ。保存済みの履歴についての古い説明を訂正 |
| 学習 | 次の課題とレビュー待ちを先に表示。全カリキュラムは折りたたみ。提出画面の未提供AI採点と固定の参考コメントを整理し、実際の提出状態と成果物への導線を表示 |
| メンター | 提出レビュー・判断を短い表現に統一。未提供のAI採点・履歴は小さな補足へ |
| 管理・通知 | 管理画面の説明と権限・状態ラベルを整理。監査の技術情報は詳細へ。通知設定を折りたたみ、通知内容を優先 |

## 維持した制約

- 保存済みの承認・評価を任意に上書きできるようにはしていない。
- 独立確認、本人評価の禁止、権限別の操作、評価期限、取消理由、編集競合の確認を維持。
- AI採点・演習実行・メール／Pushは引き続き未提供。短い説明へ変更し、利用可能という表現にはしない。
- 課題名やユーザーが記入した根拠など、業務データそのものを一括書き換えてはいない。一覧で省略した内容は詳細で確認できる。
