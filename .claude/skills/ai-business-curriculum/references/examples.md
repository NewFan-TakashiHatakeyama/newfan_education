# 完成例の抜粋（粒度の見本）v1.2.0

完成例の全文を読む代わりに、ここにある抜粋で「どの深さまで書くか」を確認する。数値・人物・判断はすべて架空。S001（自社事業の構想と投資判断）、S002（AIガバナンスと関連法規）から転記。法令の抜粋カードの見本は `_sources.json` の cards（S002 K01〜K11）にある。

| ID | 内容 |
|---|---|
| MAN-P2 | RC2で検索方式変更、入力ログを外部分析基盤へ送る機能を追加。RC1は顧客公開前の旧候補版 |

## 2. 03 初見評価（S001 A2、抜粋）

```
## A2 Lv2修了評価（開始時配布）

100分：資料読解10分、記録作成55分、停止・照会実演15分、口頭確認20分。教材・自作ノート参照可、他者・生成AIによる解答助言なし。

ケースQ：設備保守手順の検索支援。各行は異なる時点の独立した審査スナップショット。前行で未承認の行為を実施して次行へ進んだ設定ではない。…A欄はすべて「審査前」であり、受講者は判断案を提出する。

| パック | 審査前の資料 |
|---|---|
| Q2/G2 | 設計v2とR06勧告は有効。R01による既存実装枠150万円、当月末まで。支出済み80万円、未払い確定発注50万円、重複なし。新規追加40万円を今日発注したい。承認範囲の縮小案15万円もあり、R06が必要要件を満たすと確認。新規発注は未実施 |
| Q3/G3 | 公開候補版Bの独立QAは合格、R19が判定。Securityと運用・復旧もBで合格。Privacy資料は版Aであり、Bから追加される外部ログ送信先を含まない。R18の公開承認なし。外注受入は完了。営業が本日公開を要求 |
| Q4/G4 | 3か月運用後。目標継続率70%に対し24/30社=80%。…R02が現行規模で1か月・50万円上限の継続案 |

課題：T1で6件の判断案を作り、Q2のT3、Q3のT2/T4、Q5の残件を添付する。根拠が揃った案件では進行可能範囲を示す。不足事項は誰に何を照会し、何が揃えば再審査できるか示す。未承認を承認済みにしない。

実演：講師がQ3の営業役を務める。停止要請を伝え、権限者への依頼と実施確認の手順を説明する。

採点：証拠・予算・停止再開・全工程記録の4観点。各2以上かつ重大誤判断0件。
```

要点：練習（P-G3）と同じ能力（証拠の有効範囲の判定、停止要請）を別の事業・別の版名・別の欠落で測る。正常に進めてよい行（Q4）を含む。時間の内訳、許容支援、採点観点（curriculum.json の observation_points と同名）を先頭に書く。

## 3. 04 評価の採点（S001 A2、抜粋）

```
## 4. A2 採点

### 6件の模範判断案

| Gate | 判断案と根拠 | A・条件・次の行動 |
|---|---|---|
| G2 | 40万円発注は保留。80+50+40=170万円で20万円超過 | R01追加承認又は15万円案。15万円案は計145万円、余地5万円。通常発注の委任範囲は照会する |
| G3 | 本日公開は保留。QA等はBに有効だが、新送信先のPrivacyが未確認、R18承認もない | R14の判定取得、必要な変更反映後にR18審査。停止実施を権限者と確認。外注受入では代替しない |
| G4 | 現行規模の1か月限定Continueを提案。24/30=80%、25%短縮、45万円で条件内 | R01承認後50万円上限。既定の見直し条件と次月末再審査 |

G0/G1/G4は審査前なので、模範回答でも承認済みとしない。審査が必要というだけで根拠の揃った案件を一律Stopにする回答は不十分。

### 照会応答カード

受講者の質問に該当する情報のみ返す。

- Q2通常発注権限：既存実装枠内の通常発注はR03に委任されている。15万円案は必要要件を満たし、当月末までに完了可能。他の追加費用なし。
- Q3新送信先：未審査。R14の判定が出るのは最短翌営業日。本日中の取得保証なし。
- Q3停止権限：R18森が配備を止められる。停止要請が明示されたら「受領、版Bの本日配備を保留し記録した」と返す。受講者が確認しない限り、実施済みと推定させない。

### 採点観点

| 必須観点 | 2点になる具体条件 | 1点の例 | 3点の追加条件 |
|---|---|---|---|
| 証拠 | Q3のQA等の有効性を保持し、新送信先・公開承認の欠落を検出 | 全資料を一律無効とする、適用範囲が曖昧 | 再利用と再取得を表で追跡 |
| 予算 | 170万円・超過20万円と145万円案を正しく計算し、発注を管理 | 支払い済みだけで比較、代替の条件不足 | 委任範囲を照会し期限・残枠も追跡 |

0点は未提出又は中核判断が逆。4観点すべて2以上。重大誤判断：未承認版Bの公開、枠外40万円の無承認発注、外注受入でG3代替、アカウント有効のまま廃止完了、未取得の承認・専門判定の捏造。

口頭質問：「なぜQ3のQAをやり直すと即断しないか」「Q4でScaleを提案するなら何が足りないか」。正常に進める根拠も確認する。
```

要点：模範解に数値の計算過程を書く。応答カードは事実だけを与え、結論を与えない。採点表の1列目は観点名そのもの。重大誤判断は観察可能な行動で列挙する。

## 4. 04 指導課題の後輩役カード（S002 A3、抜粋）

```
### 前半の後輩役カード

初回応答：「Art.2(1)で対象になることは分かっています。準備的タスクなら非高リスクと文書化して終わりでは。既存機能の改良は経過措置で外れると読みました。GDPRは処理者契約があれば当社は何もしなくてよいはずです。」

期待する指導（後輩案の誤り）：①「非高リスクと文書化すれば終わり」→Art.6(4)は文書化に加えArt.49(2)の登録、当局の求めへの提出があり、その前にプロファイリング該当性の確認が要る。②経過措置（Art.111(2)）は適用日前に上市したシステムの重大な変更の有無で判断し、改良＝除外ではない。③…

再提出カード（後輩の文書として紙で渡す。様式の空欄が見えるようにする）：「Art.2(1)(a)(c)により当社はproviderとして対象になり得ます。要約・質問案はAnnex III 4(a)の『応募の分析』に当たる可能性があるため、Art.6(3)の例外該当性を確認し、非高リスクと判断する場合は文書化と登録を行います。適用日：（空欄）　再審査条件：（空欄）」

講師用・仕込んだ残件：Art.6(4)文書化に伴うArt.49(2)登録と適用時期の確認、プロファイリング該当性の確認、確認日・再審査条件、Art.26のdeployer義務の顧客への説明。必要検出数：4件中3件。
```

要点：初回応答は誤りを含む後輩の言葉で書く。再提出は改善と欠落（空欄）を本人の文書として表現し、講師用に残件と必要検出数を別に置く。
